# Проверка окружения Stalcraft

Проверка выполнена 3 октября 2026 года. Дополнительно скачивать Minecraft через Launcher для этой тестовой копии не требуется.

## Подготовленное окружение

Тестовый каталог: `E:\Stalcraft project\stalcraft-decompiled\.cache\runtime`.

| Компонент | Версия или состояние |

| Java | Portable Eclipse Temurin 8u504, 64-bit |
| Minecraft | Оригинальный клиент 1.6.4 из официального списка Mojang; SHA-1 проверен |
| Forge | 9.11.1.1345 — версия из метаданных карты, также указанная на официальной странице Forge |
| Библиотеки | Клиент и 23 библиотечных файла загружены по метаданным Mojang/Forge |
| Графика и звук | LWJGL 2.9.0 и Windows native-библиотеки; OpenAL инициализируется |
| Ресурсы Minecraft | 596 уникальных объектов legacy asset index загружены и проверены по хешам |
| Моды | 15 архивов тестовой сборки; Forge регистрирует 20 модулей, включая собственные и встроенные |

| Память | При запуске разрешено до 4 ГиБ heap; это параметр теста, не установленное минимальное требование |

Официальный список Minecraft: https://piston-meta.mojang.com/mc/game/version_manifest_v2.json

## Что проверено запуском

1. Чистый Minecraft 1.6.4 с Forge: FML успешно загрузил 3 базовых модуля; графическая и звуковая подсистемы инициализированы. Процесс продолжал работать до завершения теста.
2. Основной JAR Stalcraft без дополнительных модов: FML загрузил 5 модулей, включая Dynamic Lights и Stalker Mod; журнал содержит `Stalker GUI loaded`.
3. Сборка с дополнительными модами: FML сообщил `successfully loaded 20 mods`, Stalcraft обнаружил Smart Moving, WorldEdit инициализирован, интерфейс Stalcraft загрузился. Процесс продолжал работать до завершения теста.

Это подтверждает прохождение инициализации клиента по журналам. Пользователь затем загрузил `TheZone-test` через `start-local.cmd`: журнал подтвердил работу встроенного сервера и сохранение мира. Полноценная работа оружия и квестов ещё не проверена. Временные тестовые процессы остановлены после наблюдения за запуском.

## Параметр совместимости старой подписи

Современная Java 8 отклоняет устаревшую SHA-1 подпись клиента 2013 года. Forge сначала остановился на проверке сертификата, хотя SHA-1 всего файла точно совпал с официальным артефактом Mojang:

`1703704407101cf72bd88e68579e3696ce733ecd`.

В локальный запуск добавлен `-Dfml.ignoreInvalidMinecraftCertificates=true`. Скрипты перед каждым запуском независимо проверяют указанный SHA-1 оригинального клиента. Системный файл `java.security` не изменялся. Параметр относится к проверке Forge и не является заменой авторизации Minecraft.

## Состав тестовой копии

Из профиля исключены:

- `Sound.jar`: это AuthReplacer со сторонними адресами проверки онлайн-сессии; для одиночного локального теста не нужен.
- `Smart Moving Universal Standalone.zip`: альтернативная установка, дублирующая Forge-вариант.
- `MAtmos_r25_1.6.4.litemod`: дополнительный звук для LiteLoader, который отсутствует в этом окружении.

PlayerAPI, RenderPlayerAPI и OptiFine оставлены в общей сборке. Статически найдены пересечения классов с основным JAR, однако проверка инициализации с этими компонентами прошла. Их совместимость при игре ещё требует проверки.

Оригинальная сборка на E: не изменялась. Все копии, скачанные библиотеки, игровые настройки и журналы находятся в исключённом из Git каталоге `.cache/`.

## Обнаруженные проблемы сборки

- В `assets/stalker/items.txt` есть UTF-8 BOM и 9 лишних закрывающих скобок. Парсер выводит `ArrayIndexOutOfBoundsException` и `Error item config`, затем продолжает работу. Это проблема самого ресурса/парсера, а не отсутствие Java или Forge.
- `assets/stalker/special_clans.txt` содержит только UTF-8 BOM. Парсер особых кланов ожидает записи и также выводит исключение.
- Отсутствуют некоторые текстуры, например `crossbow.png`, `railgun.png`, `shotlight.png` и один ресурс декора. Во время теста они заменяются заглушками.
- Старый Realms-сервис недоступен; это сообщение наблюдалось в чистом и минимальном профилях и не остановило клиент.

Конфиги внутри оригинального и тестового JAR пока не исправлялись. Сначала сохранена воспроизводимая проверка исходной сборки.

## Запуск

В корне репозитория находятся `start-local.cmd` и `start-local.ps1`. Двойной щелчок по `start-local.cmd` запускает общую тестовую сборку. Используется локальное имя `LocalTest`; онлайн-токены и данные аккаунта не используются.

Запуск из PowerShell в каталоге репозитория:

```powershell
.\start-local.ps1
```

Проверка готовности без запуска игры:

```powershell
.\start-local.ps1 -ValidateOnly
```

Профили диагностики: `-Profile forge` и `-Profile stalker`. Скрипт `scripts/launch_runtime.py` дополнительно поддерживает ограниченный по времени тест через `--check-seconds`.

Копия карты `TheZone-test` лежит в `game/saves/`. Текстурпак `STALCRAFT-original` включён. В Minecraft 1.6.4 он выбирается настройкой `skin:STALCRAFT-original`, а параметр `resourcePacks` этой версией не читается. Это проверено по классу настроек `aul` и репозиторию ресурсов `bjt` официального клиента. Также выставлен `lang:ru_RU`.

Повторный запуск после исправления подтвердил в журнале `Resource pack: "STALCRAFT-original"`, загрузку CTM и атласов блоков/предметов, `successfully loaded 20 mods` и `Stalker GUI loaded`. Исходные настройки сохранены в `.cache/runtime/backups/profile-fix-*`. При повторной подготовке нового окружения правильный выбор пакета записывается автоматически; существующие настройки подготовщик не перезаписывает.

Начальные настройки теста: оконный режим, низкая дальность прорисовки и выключенный звук.

Клавиши, зарегистрированные Stalker Mod по умолчанию: `R` — перезарядка, `F` — фонарик, `G` — группировка, `B` — режим стрельбы, `1/2/3` — аптечки. Назначения можно проверить в настройках управления; работа каждой механики ещё требует отдельной проверки.

## Несовпадение данных CustomNPCs

Статическая проверка `Custom.zip` выявила, что `DialogController` этой версии читает gzip-NBT `customnpcs/dialog.dat`, а `QuestController` — `quests.dat`. Они не читают лежащие рядом каталоги JSON. В исходной карте и копии есть 86 одинаковых JSON-файлов; это расширенный NBT-подобный формат с литералами `0b`, поэтому обычный строгий JSON-парсер не подходит. Некоторые русские строки уже сохранены как западная mojibake (`Êòî...` вместо `Кто...`). Все файлы байтово корректны как UTF-8; добавление `-Dfile.encoding=UTF-8` само по себе эти данные не восстановит.

Фактически читаемый `dialog.dat` в оригинале и тестовой копии одинаковый: три английских шаблонных диалога категории `Villager`. Файл `quests.dat` отсутствует. Для восстановления сценариев нужен проверенный импорт в схему установленной версии или совместимая версия CustomNPCs; перед импортом необходимо сверить идентификаторы и ссылки NPC. Эти данные пока не изменены.

Отдельно проверены два NPC рядом с LocalTest, в точках `(-4406.5,70,3812.5)` и `(-4394.5,69,3810.5)`. Их имена и реплики испорчены уже в entity NBT чанков: `Ñòàëêåð` → `Сталкер`, `Ïðèâåò, ÷óâàê!` → `Привет, чувак!`. Эти строки можно восстановить обратным преобразованием Latin-1 → CP1251 на уровне отдельных значений NBT с резервной копией. Сохранения в ходе диагностики текста не переписывались. Это отдельная задача от миграции диалогов/квестов.

При загрузке карты также подтверждены отсутствующие скины `customnpcs:textures/entity/humanmale/SkinCity#8.png` и `Rookie.png`; в `Custom.zip` этих файлов нет. Включение основного текстурпака не заменяет отсутствующие NPC-ресурсы.

## Уточнение о расширениях регионов

Первоначальная подготовка переименовала 59 файлов с кириллическим расширением `.mса` в `.mca` в тестовой копии. Позднее проверка `StalkerTransformer.transformRegionFileCache` и `MethodsHelper.renameRegionFile` установила, что Stalcraft намеренно использует `.mса` и сам переносит ванильные `.mca` в это имя при обращении к региону. Поэтому расширение не является повреждением. Подготовщик новых копий больше не переименовывает регионы. Уже работающая копия поддерживается встроенной миграцией игры; повторное массовое переименование не выполнялось.

Журналы запусков находятся в `.cache/runtime/logs/`; подробные журналы Forge и crash reports — в соответствующем игровом каталоге.

Для повторного восстановления файлов окружения используется `scripts/prepare_runtime.py`; он загружает официальные зависимости и копирует сборку, не запускает игру.
