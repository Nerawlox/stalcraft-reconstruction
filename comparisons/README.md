# Build comparisons

Cross-build comparisons belong here, with explicit identifiers, input hashes, and limitations. `client212` has an unknown build and map date; `pre-2017` refers to the OFT preload published in the source VK post on 3 November 2017, with packaged file timestamps from 29 October. Do not infer a precise chronological order for every component.

An existing resource comparison is preserved in [alex-resource-comparison.json](../builds/pre-2017/analysis/alex-resource-comparison.json). Its historical filename reflects the original download label; it does not identify the author of either build. The comparison found a small number of matching image bodies and audio files, which does not establish common provenance for the complete clients or worlds.
