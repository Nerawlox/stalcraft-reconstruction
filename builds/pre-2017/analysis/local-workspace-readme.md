# STALCRAFT Pre 2017: восстановленный код

Получены все 30 715 защищённых class files. Для игрового кода и зависимостей нормализованы команды методов; CFR успешно создал 10 047 Java-файлов. Оригинальная сборка сохранена отдельно без изменений.

## Открытие в IDE

В IntelliJ IDEA открыть папку `ide-project`. В проект подключены `classes-standard.jar` и `libs-standard.jar` вместе с исходниками из `decompiled-standard`. Классы доступны в External Libraries для поиска типов/методов и перехода к исходникам. Если IDE запросит SDK, выбрать установленный JDK; язык исходного игрового байткода не выше Java8, bundled runtime исходной сборки — Java9.

В VS Code открыть `stalcraft-2017.code-workspace`. Там отдельные корни для игрового кода, библиотек и отчётов; автоматическая сборка отключена.

Это проект для исследования и навигации по восстановленному коду. Компиляция всего исходного проекта ещё не настроена: остаются обфусцированные имена, ссылки на unnamed package и отдельные методы с предупреждениями CFR. Проект не содержит задания запуска игры или входа в аккаунт.

## Каталоги

- `decompiled-standard/classes` — 5 519 Java-файлов игрового архива, Minecraft/Forge и встроенных модов.
- `decompiled-standard/libs` — 4 528 Java-файлов зависимостей.
- `recovered-bytecode/*-standard.jar` — обычный нормализованный байткод для анализа.
- `recovered-bytecode/*-recovery.json` и `*-opcode-normalization.json` — соответствия исходным payload, SHA-256, проверки.
- `analysis/restoration-status.md` — механизм, воспроизводимые скрипты, результаты и ограничения.
- `decompiled-alternatives/procyon-core` и `procyon-libs` — отдельные версии девяти файлов, у которых CFR сообщил проблемы; основной снимок сохранён неизменным.
- `runtime-diagnostic` — ранее разрешённая диагностическая копия защищённой Java; успешный запуск этой Java не получен.

Промежуточные `*-recovered.jar` сохраняют нестандартные opcodes. Каталог `decompiled/classes` — ранняя неуспешная попытка до исправления opcodes; актуальные исходники находятся в `decompiled-standard`.

Удобные точки входа: `com/stalcraft/StalcraftMod.java`, `gloomyfolken/mods/core/main/GloomyCore.java`, `net/minecraft/launchwrapper/Launch.java`.

Декомпилированный снимок сохранять отдельно от будущих ручных исправлений для пересборки. Игра и восстановленные классы не исполнялись. Сервер, локальный мир и offline пока не проверены.
