# Поиск билдов STALCRAFT 2016–2017: репозитории и зеркала

Дата раунда: 2026-10-03. Область: ранний STALCRAFT времён ПРТ и переход к ОФТ, включая поиск имён архивов/клиентов и доступных репозиториев. Общие ограничения см. `E:\Stalcraft project\AGENTS.md`: оригинал существующей сборки не менять, неизвестные EXE не запускать.

## Ключевой результат

Самая перспективная подтверждённая зацепка для 2016–2017 — старое именование клиентских веток EXBO: **Сталвар** связывают с ПРТ, а **Battlecry/Батлкрай** участники связывают с ранним ОФТ/отдельным режимом. Отдельный реальный артефакт пока не получен. Появилась персональная lead к сообществу старых сборок: пользователь EXBO Forum в августе 2025 советует написать в Discord человеку `olderz`, который якобы пришлёт «карту сталвара и гайд», как играть на старом билде. Это непроверенное свидетельство без доступного публичного адреса/файла; поиск точного имени в индексируемой выдаче ничего не дал. Также в январе 2026 участник пишет, что сам играл на версии 2012–2013 годов, а друг — на версии 2015 года. На данный момент не найден публичный проверенный архив клиента Сталвар/Батлкрай или репозиторий с кодом официального клиента.

Официальная хронология EXBO определяет временной коридор особенно точно: ЗБТ — 14.07.2014, ОБТ — 03.12.2014, ЗПРТ — 22.12.2015, ПРТ — 01.01.2016, ЗФТ — 16.06.2017, ОФТ — 31.10.2017. Поэтому если под «годом младше ПРТ» имеется в виду клиент примерно 2017 года, наиболее релевантные ключевые слова — `ЗФТ`, `ОФТ`, `Battlecry`, `Батлкрай`, `сталкрафт офт`, а для начальной точки сравнения — `Сталвар`, `ПРТ`, `сталвар клиент`.

## Отсечённые ложные совпадения

- [CurseForge StalCraft](https://www.curseforge.com/minecraft/mc-mods/stalcraft) — отдельный авторский строительный мод для Minecraft 1.10.2, версия 0.3 от 21.11.2017. Описание прямо говорит о блоках/строительстве и выживании. **Это не клиент EXBO STALCRAFT и не искомая ПРТ/ОФТ сборка.**
- Современные поисковые результаты `OFT Legacy` на Minecraft Inside описывают новый мод 1.12.2, опубликованный в 2026 году как ностальгическую реконструкцию. Это фанатский производный проект, не оригинальный билд 2017 года.
- Подходящий исторический клиент в выборочной выдаче GitHub/GitLab/Internet Archive не обнаружен. Результаты по `stalcraft` смешиваются с текущим standalone EXBO клиентом, документацией API и Minecraft-модами-клонами.

## Результаты проверки доступности

- Открытие старой ссылки `yadi.sk/d/sfIJXc7x3H2vCC` через веб-поиск не открыло содержимое диска. Поиск по URL подтверждает, что это упоминалось в посте 2017 года; размер, имена файлов, контрольные суммы и текущая доступность не установлены.
- GitHub: выполнены точечные веб-запросы `site:github.com STALCRAFT Minecraft` и `site:github.com "StalCraft" "1.6.4"`; найден только современный сторонний API-документ `Art3mLapa/unofficial-stalzone-api` (не игра/клиент). GitLab: запросы `site:gitlab.com stalcraft minecraft 1.6.4` не дали относящегося репозитория. Это выборочная выдача, полное сканирование поисковых индексов/форков не проводилось.
- Internet Archive Advanced Search по `stalcraft` (параметры: `q=stalcraft&fl[]=identifier,title,year&output=json&rows=50`) вернул 18 предметов; проверенные заголовки относятся главным образом к wiki, видео/музыке и посторонним объектам. Исторический игровой клиент среди доступных результатов не обнаружен. Поиск выдачи, не полный аудит IA.
- Wayback CDX напрямую через Python urllib доступен: [CDX 2016](https://web.archive.org/cdx/search/cdx?url=*.stalcraft.ru/*&output=json&filter=statuscode:200&filter=timestamp:2016&collapse=urlkey&fl=timestamp,original,mimetype,statuscode,length) и [CDX 2017](https://web.archive.org/cdx/search/cdx?url=*.stalcraft.ru/*&output=json&filter=statuscode:200&filter=timestamp:2017&collapse=urlkey&fl=timestamp,original,mimetype,statuscode,length). В снимках найдены старый сайт и статика, также старый форумный домен; в просмотренных HTML/CDN-результатах клиентский ZIP/JAR/EXE не обнаружен. Изучена [архивная главная за 10.07.2017](https://web.archive.org/web/20170710134208id_/https://stalcraft.ru/): страница сайта/личного кабинета с новостями и ссылкой регистрации поддержки, без найденной прямой раздачи клиента. Вывод ограничен индексом и URL, которые удалось проверить.
- Не скачивал и не исполнял исполняемые файлы/лаунчеры. Архив исходников с неизвестным содержимым не принимался за безопасный/достоверный только по старой ссылке.

## Приоритетные следующие шаги

1. Идти от терминов, которые реально употребляют старые пользователи: `Сталвар клиент`, `сталвар ПРТ EXBO`, `stalcraft_ots`, `stalcraft battlecry клиент`, `батлкрай клиент`, `ЗФТ stalcraft`, плюс старые адреса официальных VK-групп/постов. Проверять изображения/видео и упоминаемые папки/названия архивов как новые поисковые ключи.
2. Проверить доступность старого Яндекс.Диска через интерфейс/архивные индексаторы и искать копию URL или вложенного ZIP по исходному URL, имени темы, автору `GloomyFolken` и `NetCS`. При появлении архива сперва снять метаданные/хеш, перечислить содержимое без запуска и установить, является ли он кодом мода, декомпиляцией или клиентским комплектом.
3. Для целевого 2017 клиента продолжать поиск вариантов `Battlecry`, `stalcraft_ots`, `stalcraft_battlecry`, старых launcher manifests и клиентских папок. Форумное свидетельство о side-by-side install позволяет искать названия в дампах дисков и пользовательских архивных торрентах.
4. Проверить публичные ссылки/посты, связанные с `olderz`, и Discord-контекст сообщения #66 темы карты; пока это только устная рекомендация сообщества без проверки и прямого контакта.
5. Спросить автора Reddit-поста о видео 2016 года о возможных исходных файлах/названиях серверов. Извлечённые из видео сведения использовать как направления поиска, а не как доказательство даты билда.

## Дополнительная проверка API/Wayback (2026-10-03)

- Прочитан README репозитория [unofficial-stalzone-api](https://github.com/Art3mLapa/unofficial-stalzone-api/blob/main/README.md): он документирует текущую API-структуру лаунчера, `listServers`, `torrentData`, CDN и torrentData hash paths; в частности, описан `dev-cdn.xexbo.ru` с id `stalcraft_ots` и HTTP seeds для актуальной игры. В качестве примера приводится хеш `650b0b1fe42db383ada4a257abbea87171c87102`. Данные относятся к современному лаунчеру и не показывают старые исторические ветки/идентификаторы сами по себе.
- Без авторизации запрошен публичный `https://launcher.stalcraft.net/launcher?list=true`. Ответ 457 байт перечисляет только launcher runtime (`native/jlibtorrent.dll`, `launcher.jar`, `native/registry.dll`, `native/ExboOptimizer.exe`, `args*.txt`) с размерами и SHA-1; игровых билдов там нет. Запрос `listServers` без нужных параметров вернул HTTP 400, дальнейший подбор параметров, токенов и авторизационных вызовов не выполнялся.
- Обсуждение карты Сталвара через публичный Flarum API просмотрено целиком (посты 1–69): подтверждается и опровергается в самой теме, что за изображениями нет доступного общедоступного бинарника. Пост #66 — единственная конкретная lead к человеку/гайду, пост #68 — устное заявление о локальном запуске двух версий.
