# Поиск по именам JAR и старым пакетам

Дата проверки: 2026-10-03. Цель: точные строки `stalker_client212.jar`, `stalker_client`, `zclient.jar`, `ThereIsNoWay`, плюс сочетания с Minecraft 1.6.4, STALCRAFT/ЗБТ/SSOM, REAT и Zonecraft. Искомый результат — старый архив клиента или фанатской сборки с проверяемым источником и живой ссылкой. Никакие EXE/лаунчеры не скачивались или запускались.

## Самая сильная новая зацепка: `zclient.jar` / `ThereIsNoWay`

[Вопрос Ответов Mail: «Краш в minecraft stalcraft збт ssom помогите решить проблему»](https://otvet.mail.ru/question/200608651) (страница показывает возраст «9 лет», ориентировочно 2017 год, точная дата публикации на доступной странице не отображена) содержит исходный crash-report Minecraft ForgeOptiFine 1.6.4 с записью:

```text
ThereIsNoWay{1.0[1.6.4]} [[MP] ThereIsNoWay] (zclient.jar)
Unloaded->Constructed->Pre-initialized->Errored
```

Автор вопроса пишет, что скачал сборку и называет её «мод на сталкер в minecraft». Это подтверждает, что в обращавшемся пакете для Minecraft 1.6.4 был Forge-мод `ThereIsNoWay` версии 1.0, упакованный/названный `zclient.jar`. Страница не доказывает связь с EXBO или официальным STALCRAFT: маркировки `ЗБТ SSOM` и слово «сталкрафт» находятся в пользовательском заголовке, а автор описывает именно Minecraft-мод/сборку.

Вопрос указывает на старую публичную ссылку `https://yadi.sk/d/xDpFmlgB3HVGKS`. Проверил прямые URL `yadi.sk/d/xDpFmlgB3HVGKS`, `disk.yandex.com/d/xDpFmlgB3HVGKS`, `disk.yandex.ru/d/xDpFmlgB3HVGKS` и публичные Yandex Disk API `resources` / `resources/download`: все вернули HTTP 404. Запрос Wayback CDX по точному URL не завершился по таймауту, поэтому архивного снимка ссылки не подтверждено. Имя архива, состав файлов, дата, размер и хеш неизвестны. Это **не живая ссылка**, а архивная зацепка; содержимое и происхождение сборки не проверены.

## Что проверено и что остаётся

- Использованы точные запросы по всем четырём именам, затем сочетания `ThereIsNoWay` / `zclient.jar` / `Minecraft 1.6.4` / `сталкрафт ЗБТ SSOM`, ключу Яндекс.Диска, `REAT` и `Zonecraft`.
- На данный момент не обнаружено ни одного живого общедоступного архива, который можно статически инвентаризировать. Единственная новая архивная ссылка по точным JAR-именам возвращает 404.
- Не скачивались архивы с неизвестным содержимым. Не запускались EXE, лаунчеры или JAR.
- Следующая полезная зацепка — искать перепост именно ключа `xDpFmlgB3HVGKS`, имени мода `[MP] ThereIsNoWay` и участника `vitalia_gazhulenko`, а также искать другие публичные crash-report/log-сниппеты с теми же mod-id и JAR-именем. При обнаружении зеркала сначала записать URL, время получения, размер и SHA-256, затем перечислить состав архива без запуска; отдельно определить, мод это, сборка Minecraft или официальный клиент.
