## Состояние архивных ссылок

Статусы относятся к конкретным проверочным маршрутам, их нельзя смешивать:

- **Yandex Disk Public API 404 (`DiskNotFoundError`)** — публичный API не нашёл ресурс. Это не доказывает отсутствия копий/зеркал и не эквивалентно скачиванию файла.
- **HTTP GET 404** — обычный HTTP-запрос к ссылке завершился 404; без API-ответа нельзя приписывать ему `DiskNotFoundError`.
- **Yandex Disk Public API 429 (`DiskResourceDownloadLimitExceededError`)** — лимит загрузки; считать архив удалённым нельзя.
- **HTTP 405** на HEAD — метод не поддержан; отдельно не указывает, жив ли ресурс.
- **TLS timeout** — статус неизвестен.

## Следы не привязанные к конкретному видео

- https://otvet.mail.ru/question/200608651 — старый вопрос о сбое Minecraft 1.6.4. Автор указывает архив `xDpFmlgB3HVGKS`; crash report показывает `ThereIsNoWay{1.0[1.6.4]}`, mod label `[MP] ThereIsNoWay`, `zclient.jar`, `ForgeOptiFine 1.6.4` и состояние `Unloaded->Constructed->Pre-initialized->Errored`. `ThereIsNoWay` трактуется как профиль/имя сборки в логе, а не как подтверждённое официальное название.
- Отдельный кандидат-карта: страница https://ru-minecraft.ru/karty-dlja-minecraft/48628-the-zone-chernobyl-exclusion-zone-ona-zhe-stalcraft-mega-karta.html (дата страницы 02.06.2017) ведёт на архив `https://yadi.sk/d/TPU2Rfe83JkLn7`. Yandex API вернул 200; файл карты скачан координатором: 543,203,637 байт, SHA-256 `bce3b4c3ca045ffea75fa8567807f77b51dfb28bec64d5cdcaaef81025330815`. Есть сильное сходство с текущей картой по разбору координатора; возможный источник — страница Planet Minecraft «Pripyat City» пользователя tsarcorp, обновлена 03.01.2017: https://www.planetminecraft.com/project/pripyat-city/. Это именно кандидат карты, не отдельная клиентская сборка; приписывание автора требует сопоставления самой географии/данных. Не связывать карту с конкретным видео без доказательств.

## Официальная хронология и осторожность в выводах

[Справка EXBO о стадиях STALCRAFT](https://support.exbo.net/ru/help-center/articles/16/17/220) датирует начало ПРТ 01.01.2016, ЗФТ 16.06.2017, ОФТ 31.10.2017. Это подтверждает календарь официальных стадий, но не происхождение пользовательских Minecraft-сборок. Называние видео «ПРТ», «ОБТ» или «ЗБТ» само по себе не доказывает, что оно содержит официальный исторический клиент.

Самая сильная связь с текущей сборкой — повторяющийся URL `dmYU5l341l_NHg`, одинаковый в пользовательском исходном видео 2019 года и его зеркале описания на Portall. Статус API 429 означает ограничение загрузок, поэтому архив не следует считать удалённым. При этом совпадение URL ещё не заменяет сравнение SHA-256 архивов, JAR и сохранения мира.

## Ограничения и дальнейшие шаги

- Удалённые архивы могут иметь зеркала, не найденные в текущей выдаче; API 404 не исключает перепубликацию.
- Самые перспективные ключи для поиска копий 2017 года: `e1lQcvtB3KDaLS` (одна ссылка в двух роликах), затем `poDjJRXx3LQN5T`, `sfIJXc7x3H2vCC` и `xDpFmlgB3HVGKS`.
- Для утверждения, что найденный архив совпадает с конкретным клиентом/миром, требуются статическое содержимое, имена, размер и SHA-256. Не запускать неизвестные EXE/лаунчеры и не объединять файлы разных сборок.
